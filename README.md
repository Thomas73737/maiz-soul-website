# Maíz Soul by Tía Yaya — website assets

## Asset structure
- `public/images/brand/` — logo / brand image
- `public/images/hero/` — homepage hero image
- `public/images/food/` — food photography
- `public/images/drinks/` — drinks photography

## Download images
If the archive's image folders are empty, run this on a computer with internet access:

```bash
python3 download_images.py
```

No extra Python packages are required. The script downloads each image into the correct folder and prints any failures.
